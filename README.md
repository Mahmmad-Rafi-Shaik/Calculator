# Calculator

## Project Description
The Calculator project is a simple yet powerful tool designed to perform basic and advanced arithmetic calculations. It serves as an educational tool for learning and understanding fundamental math operations.

## Features
- Basic arithmetic operations: addition, subtraction, multiplication, and division.
- Advanced calculations: square roots, powers, and trigonometric functions.
- User-friendly interface for easy navigation and input.

## Technology Stack
- Programming Language: JavaScript
- Frontend Framework: React
- CSS Framework: Bootstrap
